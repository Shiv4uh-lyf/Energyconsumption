03 Anomaly Detection & Explainability
Hybrid Anomaly Detection
  • Rolling Z-Score — flags readings deviating >2.5σ (UNUSUAL) or >3.5σ (HIGH) from a 168-hour rolling mean.
  • Isolation Forest — unsupervised tree model using consumption value, hour-of-day, day-of-week, and rolling statistics as features.
  • Both algorithms run in parallel; results are deduplicated by timestamp, keeping the highest severity label per event.
SHAP Explainability
  • TreeExplainer for XGBoost & Random Forest — exact Shapley values from tree structure.
  • LinearExplainer for Ridge Regression — SHAP on scaled coefficient space.
  • Top-20 per-feature mean absolute SHAP contributions surfaced with human-readable descriptions (e.g. "lag_168: same hour last week — strong weekly periodicity").

05 Key Differentiators vs. Typical Prediction Models
  • 🎯
    Adaptive Ensemble Weighting — ensemble weights are computed from actual validation-set MAE at runtime. The best-performing model automatically receives the highest contribution. No hardcoded weights ever.
  • 🔒
    Guaranteed Leakage Safety — every lag and rolling feature uses .shift() with positive offsets. The chronological splitter raises a hard error if data is not monotonically time-ordered. Common in research; rare in practice.
  • 🛡️
    Two-Stage Hybrid Anomaly Detection — statistical (Rolling Z-Score) and model-based (Isolation Forest) pipelines run independently, covering both distributional and structural anomalies, then merged with severity-aware deduplication.
  • 🧠
    Full Explainability Loop — SHAP values per model expose exactly which feature drove each prediction up or down, making forecasts auditable and trustworthy for grid operators.
  • 📐
    Production Architecture — not a notebook. Full FastAPI REST backend with Pydantic schemas, Next.js 14 App Router frontend, Docker Compose, Render deployment config, and a single-command launcher (start_app.bat).
  • 📊
    Live Multi-Metric Benchmarking — all 8 models are evaluated on the same held-out test set and ranked by MAE, RMSE, MAPE, R², and inference latency simultaneously, with a live leaderboard in the UI.
